# 🚖 Ride Booking & Fare Analysis Dashboard

An interactive Power BI dashboard built to analyze **150,000+ ride-booking records**, explore booking performance, understand cancellation patterns and examine fare-related metrics.

## 📌 Project Overview

The Ride Booking & Fare Analysis Dashboard is a data analytics project developed using **Power BI, Power Query and DAX**.

The project focuses on exploring ride-booking data through interactive visualizations, helping users understand booking outcomes, cancellation patterns and available fare-related metrics.

## 🎯 Project Objectives

- Analyze ride-booking data and booking performance.
- Understand completed and cancelled booking patterns.
- Explore customer and driver cancellations.
- Analyze fare-related metrics and ride information.
- Present relevant metrics through interactive visualizations.
- Develop practical skills in data transformation, DAX, and business intelligence.

## 📊 Dashboard Features

- **Booking Analysis:** Explore booking records and booking outcomes.
- **Cancellation Analysis:** Examine cancellation patterns and cancellation reasons.
- **Fare Analysis:** Analyze available fare-related metrics.
- **Ride Analysis:** Explore ride-related information and available categories.
- **Interactive Visualizations:** Explore the report using available filters, slicers and charts.

## 🔄 Project Workflow

1. **Data Import:** Imported the ride-booking dataset into Power BI.
2. **Data Cleaning:** Used Power Query to prepare and transform the data.
3. **Data Transformation:** Prepared columns and data types for analysis.
4. **DAX Calculations:** Created measures for relevant analytical metrics.
5. **Data Visualization:** Developed interactive charts and report visuals.
6. **Analysis:** Explored booking performance, cancellations and fare-related trends.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Install [Microsoft Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).
3. Open the `.pbix` report file.
4. Configure the data source if prompted.
5. Refresh the data if required.
6. Explore the available report pages and interactive visualizations.

*The dataset may need to be downloaded separately if it is not included in the repository.*
